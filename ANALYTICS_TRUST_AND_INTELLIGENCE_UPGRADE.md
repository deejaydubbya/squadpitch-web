# Analytics Trust & Intelligence Upgrade

## Overview

This upgrade makes the analytics system a trustworthy, data-backed decision engine by surfacing evidence that was already computed by the backend but not displayed.

## Metric Type Separation

Every analytics section carries a badge indicating data provenance:

- **Measured** (blue) — Direct from platform APIs (likes, reach, impressions)
- **Derived** (amber) — Calculated from measured data (averages, benchmarks, rates)
- **AI Analysis** (purple) — Generated by the scoring engine, not from platform metrics

Badge tooltips explain these categories on hover.

## Evidence-Based Insights

Insight cards now display an evidence footer showing:
- **Score**: The average composite score for that insight's cohort
- **Gap**: How many points above/below the baseline
- **Sample size**: Number of posts analyzed (n=X)

Confidence is shown as a labeled badge ("High confidence" / "Medium confidence") instead of a bare dot.

## Confidence Indicators

- **Insight cards**: Labeled confidence badge (green/amber)
- **Recommendation cards**: Confidence badge next to category tag
- **Metric cards**: Sample size always visible — amber for < 10 posts, gray for 10+

## How Confidence Is Calculated

Confidence is computed server-side in `insights.service.js` and `recommendations.service.js` based on:
- Sample size (more posts = higher confidence)
- Score gap magnitude (larger gaps = higher confidence)
- Data coverage (engagement data present = higher confidence)

## "Needs Attention" Reasons

Worst-performing posts now carry an explanation label computed by `computeWorstReason()`:
- "Low engagement from platform metrics" — observedScore < 30
- "Score well below your average" — compositeScore < avg * 0.6
- "Engagement rate far below average" — ER < avg * 0.3
- "Very low distribution" — impressions < 10
- Fallback: "Underperforming vs your average"

- **Issue** (amber): Low data coverage or other problems
- **Opportunity** (green): Top insight or autopilot winning
- **Focus** (blue): Top recommendation action

### Autopilot Takeaway (Intelligence tab)

- Amber: "Manual posts are outperforming Autopilot by X points"

### Empty States

## Remaining Limitations

- Confidence thresholds are fixed (not configurable per workspace)
- `computeWorstReason` uses simple threshold comparison — not ML-based
- Focus cards are computed client-side from existing data (no dedicated endpoint)
- Supporting metrics format depends on the insight type — not all insights populate all fields
