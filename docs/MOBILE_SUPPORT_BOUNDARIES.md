# Mobile support boundaries

The workspace supports day-to-day use at 320–430 px without changing API,
authorization, entitlement, or provider behavior.

## Supported mobile workflows

- Properties and other industry inventory: browse, search, filter, inspect,
  add, edit, archive, and start content creation. Vehicle inventory uses the
  same business-data card workflow rather than a separate vehicle route.
- Contacts: conversation list, contact detail, messaging, and provider-backed
  reply actions through Inbox.
- Campaigns: status, post detail, approvals, scheduling, publishing, and basic
  management through the Planner agenda.
- Analytics: high-signal summaries, charts, range selection, and section tabs.
- Integrations: readiness, connect/reconnect, enable/disable, tests, delivery
  status, and simple configuration.
- Workspace settings and billing: navigation, form controls, usage, plan
  selection, and the existing Stripe customer-portal flow.

## Desktop recommended

- Constructing complex multi-post campaigns or using advanced create modes.
- Dense calendar planning and drag-and-drop scheduling.
- Large-scale inventory/data bulk operations.
- Reviewing wide or highly detailed analytics comparisons.
- Complex integration event mapping and high-volume delivery-log review.

These workflows remain available and unchanged on desktop. Mobile does not
introduce alternate credentials, billing logic, provider state, or fake data.
